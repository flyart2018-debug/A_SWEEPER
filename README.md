# SWEEPER — ROOT FLAT VISUAL ALPHA

GitHub Pages向けのルート直下完結プロトタイプです。

## 操作
- NEW GAME → REN / KAI選択
- 5×5をタップして上下左右1マス移動
- 敵タップで上下左右の直線3マス射程を判定
- 斜め攻撃不可
- ソード / ショット / シールド / ダッシュ / リカバー
- 固有チップ：オーバーブレード / アクセルステップ
- CPU AI / HP / ログ / リザルト / REMATCH

## Visual assets
添付されたSWEEPERキャラクター設定画・モーション資料・チップ資料から、ゲーム内で使う部分を切り出したPNG/JPGをルート直下に配置しています。設定画そのものをゲーム画面に丸ごと表示しません。
